# CoinDCX V6 - AI Cryptocurrency Trading Bot

A modular Python-based cryptocurrency trading bot designed for the CoinDCX exchange. The project focuses on building a scalable trading framework with paper trading, technical analysis, risk management, and real-time notifications.

> **Status:** Active Development

---

## Overview

CoinDCX V6 is an experimental algorithmic trading framework created to explore systematic cryptocurrency trading using technical indicators and rule-based strategies.

The project emphasizes:

- Clean and modular architecture
- Paper trading before live deployment
- Risk management
- Strategy experimentation
- Performance tracking
- Continuous improvements

---

## Features

- 📈 Technical Indicator Based Trading
- 📊 Market Trend Analysis

- 🧪 Paper Trading Support

- ⚠️ Risk Management System

## Installation

Clone the repository:

```bash
git clone https://github.com/aamirkareem3/CoinDCX_V6.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Configure your settings:

- Exchange API credentials
- Telegram Bot Token
- Trading parameters

Run the trading bot:

```bash
python engine.py
```
